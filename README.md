# Single-Image Resizing (`feat/resize`)

A lightweight Python and OpenCV (`cv2`) utility script for loading a single image and resizing it to target pixel dimensions.

## Feature Overview
- **Script:** `resize_image.py`
- **Purpose:** Quickly tests OpenCV image loading and resizing on a single sample image to verify environment setup and output dimensions.
